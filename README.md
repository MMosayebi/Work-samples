# Project List

Below is the complete list of my projects along with a brief description of each:

### 1- Uber
- The Uber project involves analyzing trips taken in 2016 (Source: Kaggle). In this project, topics that can help estimate arrival time from origin to destination (based on the distance between the two locations) are presented, and the final equation has been derived.

### 2- HearAttack
- The Heart Attack project (Source: Kaggle) is based on recorded patient data. The goal of the project is to predict the probability of having a heart attack, which has been trained using a logistic regression model. Additionally, the final section, which involves identifying patients at risk of a heart attack, has been carried out with the help of artificial intelligence to achieve the best possible outcomes.
